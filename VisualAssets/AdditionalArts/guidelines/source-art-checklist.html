Source-Art Request Checklist

Send this to your artist or image generator to get production-ready raw exports — not catalog/preview montages. The montages received so far (icons, characters, tileset) are useful references but are opaque, upscaled, and wrapped in UI chrome. Every deliverable below must satisfy the Golden rules first. Pairs with the Asset Pipeline card.

00 Golden rules — reject a delivery that fails any of these

  • Transparent PNG-32 (real alpha) — no baked background, panels, or slot frames.
  • Native resolution — authored at true pixel size (see table), not upscaled then shrunk.
  • No chrome — no titles, palettes, legends, frame numbers, drop shadows, or glow bleeding past the sprite.
  • Uniform grid, margin 0 / spacing 0, one cell = one frame/tile.
  • Consistent pivot across every frame of an actor (feet bottom-center).
  • Deliver the raw sheet files + a plain frame-count list; montage previews optional.

03 Tileset atlas (per biome)

  • 16×16 tiles, margin 0 / spacing 0, one atlas per biome — Slums, Undercity, Wasteland, Lab, Neo-Solis (matches env palettes).
  • Include auto-tile / terrain sets: request the 47-tile (blob) or Godot terrain layout for ground, water, cliffs — not just loose tiles.
  • Mark which tiles are solid (collision) vs walkable vs overhead (roofs that fade); a collision key image or list.
  • Tiles opaque OK; anything with a soft edge (foliage, decals) needs alpha.

04 Props, architecture & 9-slice

  • Props/decoration/vehicles as a transparent packed atlas + region map (TexturePacker JSON or Godot .tres).
  • Group by biome/use; keep each atlas ≤ 2048².
  • Ornate UI frames (rarity, boss, featured) as nine-patch PNGs with stated patch margins (see Asset Pipeline §07).
  • Building kit: walls/floors/roofs/doors as modular 16px pieces with consistent connection edges.

05 Delivery, naming & format

  • PNG only (no JPG). Indexed or 32-bit, alpha straight (not premultiplied).
  • Files: actor_state_dir.png, tile_biome_variant.png, prop_biome_name.png, icon_category_name.png — lower_snake_case.
  • Zero-padded frame indices _00 _01; direction suffix _s _n _e.
  • Include a source file (Aseprite .ase ideal) so frames/pivots/tags are editable.
  • Provide a palette swatch file to confirm color-lock.
  • One contact sheet per delivery for review is welcome — as an extra, never the only file.
