Accessibility & platform

Console-and-mobile first: every interactive element must be reachable by D-pad/stick, obviously focused, comfortably tappable, and legible. The tokens below are the contract; the design-system lint already flags the raw values that would break it.
Touch / hit targets
Interactive targets are at least 44×44px — use var(--hit-target), never a smaller literal. Small glyphs get an invisible 44px padded hit area. Raw px values are lint-flagged, which pushes every size onto a spacing token including this one.
44pxmin tap area · --hit-target
Focus & controller nav
Focus is always visible: 2px solid var(--focus-ring), offset. Every screen defines a logical focus order and a sensible default focus. Movement maps to D-pad / left stick; Ⓐ confirm, Ⓑ back, bumpers switch tabs — mirror the control legend shown on each screen.

Reduced motion
Honor prefers-reduced-motion: drop transforms and parallax, keep opacity cross-fades, and collapse durations toward --dur-instant. Never gate information or feedback on an animation alone — pair it with a state change.
Contrast & legibility
Body/label text uses --fg-1/--fg-2 on --surface-* for AA contrast; never state meaning by color alone (pair with an icon or label — see status icons). In-game UI text stays ≥ 12px. Raw hex is lint-flagged so color always comes from a contrast-checked token.
Enforced by the design system
Lint (adherence): raw px → spacing token · raw hex → color token · unknown font → Orbitron / Share Tech Mono · component props validated. Tokens: --hit-target--focus-ring--dur-instant--fg-1…3--fg-disabled — build against these and the rules above hold automatically.
