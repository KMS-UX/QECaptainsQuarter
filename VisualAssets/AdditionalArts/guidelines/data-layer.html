Game content data layer

Lore, rosters and tables live once in assets/data/ as plain JSON. Preview cards fetch them, and the game engine ships the same files unchanged — no copy-paste, no drift.

Editing rule
Change data here, nowhere else. Sprite/art paths are relative to /assets; colorToken values reference tokens already defined in tokens/colors.css.
