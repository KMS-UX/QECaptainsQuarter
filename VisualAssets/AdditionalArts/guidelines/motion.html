Motion spec

Every UI motion pulls a duration + easing from these tokens. Snappy for input feedback, emphasized (overshoot) for pickups and pops, gentle for panels. Honor prefers-reduced-motion: drop transforms, keep opacity, collapse to --dur-instant.
Tokens
TokenValueUse
--dur-instant0.08sReduced-motion fallback, taps
--dur-fast0.15sHover, press, toggle feedback
--dur-base0.25sScreen & modal transitions, tab switch
--dur-slow0.4sBar fills, notification in, damage numbers
--dur-slower0.7sBoss intros, screen wipes
--ease-uicubic-bezier(.2,.9,.3,1)Default — most UI moves
--ease-outcubic-bezier(.16,1,.3,1)Enter / reveal (fast settle)
--ease-incubic-bezier(.5,0,.75,0)Exit / dismiss
--ease-emphasizedcubic-bezier(.34,1.56,.64,1)Overshoot — pops, loot, level-up
--ease-linearlinearProgress bars, timers, spinners
