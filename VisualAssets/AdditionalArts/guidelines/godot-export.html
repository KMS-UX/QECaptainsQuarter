Install (no code)

  1. Copy files into res://ui/quantum/.
  2. Autoload quantum_tokens.gd as node name Q.
  3. Set quantum_theme.tres as GUI > Theme > Custom.
  4. Import Orbitron + Share Tech Mono .ttf; set Default Font.

Usage

# rarity-tint an item name
name.add_theme_color_override(
  "font_color", Q.rarity("legendary"))

# standard UI fade-in (0.25s, cubic-out)
Q.tween_ui(create_tween()).tween_property(
  panel, "modulate:a", 1.0, Q.DUR_BASE)

# spacing + touch target
vbox.add_theme_constant_override("separation", Q.SP_3)
btn.custom_minimum_size.y = Q.HIT_TARGET  # 44
