Localization

All player-facing UI copy lives in strings.json under dotted keys. Templates call t('menu.new_game') instead of writing text inline. A sibling strings.<locale>.json overrides per language; any missing key falls back to English.

Consume it
const L = await QEContent.loadStrings(
  '../assets/data', 'ja');   // 'en' default
L.t('menu.new_game')  // ニューゲーム
L.t('shop.buyback')   // falls back to
                      // English (not in ja)
L.t('x.missing', '—') // fallback arg
Rules
Never concatenate sentences from fragments — full strings per key. Leave room: some locales run 30–40% longer, so size UI to the string, not the reverse. Keep keys stable; translators key off them.
