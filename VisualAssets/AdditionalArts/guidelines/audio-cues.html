Audio cues

UI code never names a sound file — it fires an event, and audio.json routes it to a cue. Designers re-point files without touching UI code; the engine and DS agree on the same event names.
Interface · ui.*
EventWhen
ui.selectCursor / highlight move
ui.confirmPrimary action
ui.backCancel / return
ui.errorInvalid / no funds
ui.tab_switchChange tab
ui.toggleSetting flip
ui.open / ui.closeMenu open / close
Rewards · reward.*
reward.lootItem pickup
reward.coinCredits / purchase
reward.levelupLevel / skill point
reward.questQuest updated
Combat · combat.*
EventWhen
combat.hitHit connect
combat.critCritical hit
combat.abilitySkill cast
combat.deathYou have fallen
World & system · world.*
world.saveGame saved / auto-save
world.fast_travelFast-travel warp
world.dialogueAdvance dialogue
