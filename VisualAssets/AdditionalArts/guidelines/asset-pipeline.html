Asset Pipeline Specification

How pixel art moves from source sheet → game-ready asset in Godot 4, targeting Android smartphones. One authored resolution, integer-scaled at runtime; nearest-neighbor everywhere. Aligns with the Master Tileset (16px grid) and Icon Bible (16px base).

Author for the 640×360 low-res viewport; Godot's stretch scales it to any Android panel. Never author UI at fractional pixels.

02 Godot 4 import settings — pixel-perfect (non-negotiable)

  • Texture Filter = Nearest (Project > Rendering > Textures > Default Filter = Nearest).
  • Per-texture: Mipmaps OFF, Fix Alpha Border ON, Compress = Lossless (never VRAM/ETC for pixel art).
  • Import as 2D Pixel preset.
  • Camera2D: integer zoom only (2, 3, 4…); enable Snap 2D Transforms to Pixel.
  • Project stretch: Mode = viewport, Aspect = expand, base 640×360.
  • Disable anti-aliasing (MSAA off) for 2D.

  • World scales by integer camera zoom; wider aspect = more visible playfield, not stretched pixels.
  • UI (Control layer) uses a separate CanvasLayer at device resolution — anchor to safe area, size in dp, min touch 44px. Do not integer-scale the HUD with the world.
  • Provide UI scale slider 0.8–1.2 (see Mobile / Touch HUD template); reposition-in-settings supported.

04 Sprite sheets & texture atlases

  • One uniform-grid sheet per character (all clips share cell size). Frames left→right, clips top→bottom.
  • Margin 0, spacing 0 for uniform grids read by AtlasTexture / SpriteFrames.
  • Packed/irregular atlases (props, FX): 2px spacing, 0 margin to prevent bleed; ship a .json (TexturePacker) or Godot .tres region map.
  • Max atlas 2048×2048 (safe on all Android GPUs; 4096 only if min-spec allows).
  • Format PNG-8/PNG-32, premultiplied alpha off.
  • Group by draw frequency — one atlas per actor/biome/UI set, not one mega-sheet.

4-direction minimum (S / N / E, W = mirror of E). Keep the character's pivot (feet-center) on the same pixel across all frames. Build clips as Godot SpriteFrames.

06 Tilesets

  • 16px grid, margin 0 / separation 0. Use Godot TileSet Terrain (auto-tile) for terrain transitions.
  • Per-tile collision polygon + navigation + Z / Y-sort layer authored in the TileSet editor.
  • Layer order: ground → detail → props (Y-sorted) → overhead/roof (fade on player enter).
  • Keep tileset atlas ≤ 2048; split biomes (Slums, Undercity, Wasteland, Lab, Neo-Solis) into separate atlases.

07 9-slice (nine-patch) UI panels

  • Panels/buttons/frames that resize ship as nine-patch PNG with declared margins so borders stay 1px crisp.
  • In Godot use NinePatchRect (or StyleBoxTexture) — set patch margins = source border width.

09 Budgets & format rules

  • PNG only for art.
  • Atlas ≤ 2048 (4096 max).
  • No JPG (halos on pixels).
  • Keep total VRAM textures modest for low-end Android.
  • Stream biome atlases per region.
  • Audio: OGG Vorbis (SFX/music), see Audio Cues.
  • Fonts: import Orbitron/Share Tech Mono .ttf; bitmap font for in-world.
