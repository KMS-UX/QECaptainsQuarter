HUD button in Orbitron caps; use for all in-game actions. Hover = glow, press = brighter fill, disabled = desaturated.

```jsx
<Button variant="primary">Play</Button>
<Button variant="secondary" size="sm">Equip</Button>
<Button variant="danger">Delete</Button>
<Button disabled>Disabled</Button>
```

Variants: primary (teal fill), secondary (dark, teal text), ghost (border only), danger (red). Sizes sm/md/lg; md+ meet the 44px hit target.
